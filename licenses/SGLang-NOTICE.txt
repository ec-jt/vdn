Modifications dated 2026-10-05:
- src/models/ops/csrc/vdn_delta_factors.cuh retains the CUDA device arithmetic,
  tiling, two-pivot Gauss-Jordan schedule, reciprocal refinement, packed FFMA2
  on SM100+, scalar FP32 FMA on earlier SMs, and injection GEMM. Replaced SGLang
  includes and device annotation macro with CUDA headers/annotations; renamed
  the namespace; removed the TVM host wrapper. Original SPDX and math comments
  are retained.
- src/models/ops/csrc/vdn_delta_factors.cpp and vdn_delta_factors.cu replace
  TVM FFI with PyTorch bindings, validation/allocation, current-device/current-
  stream launch, checked resource opt-in and thread-safe per-device setup.
- src/models/linear_attention/paper_factor.py adapts alignment and factor
  orientation into a strict, lazy PyTorch extension API with optional alpha.
  Unlike the upstream model dispatch it has no fallback or training path.
- tests/test_paper_stack_vda_factor.py adapts normalized-statistics and offset
  test ideas, replaces model/eager dependencies with independent CPU FP64 right
  solves, and adds contract, orientation, stream and ownership tests.

Contract: transition = diag(alpha) (I + A)^-1; injection = B (I + A)^-1.
No alpha means identity row scaling. A must make I + A SPD. Numerical/pivot
preconditions are not checked, as in the upstream nonpivoting kernel.
64 KiB dynamic plus 4 KiB static shared memory, 256 threads per 128x128 matrix.
No SGLang runtime, TVM FFI, weights or transitive SGLang dependencies are bundled.
This source port makes no new performance, accuracy or whole-model parity claim.
